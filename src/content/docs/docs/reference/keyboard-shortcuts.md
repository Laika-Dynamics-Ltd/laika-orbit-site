---
title: Keyboard shortcuts
description: Every key in Laika Orbit. Press ? in the app for the same list.
---

Press <kbd>?</kbd> in the app to see these at any time.

## Search

| Keys | Action |
|---|---|
| <kbd>⌘</kbd><kbd>K</kbd> or <kbd>/</kbd> | Spotlight: files, actions, ask |
| <kbd>space</kbd> | Preview the selected file |
| <kbd>↑</kbd> <kbd>↓</kbd> · <kbd>↵</kbd> | Move through results · open |
| <kbd>esc</kbd> | Close the panel or menu |

## Views and panels

| Keys | Action |
|---|---|
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | Map layout: ARMS · Rings · Packed |
| <kbd>[</kbd> · <kbd>]</kbd> | Toggle the left · right rail |
| <kbd>\\</kbd> | Map only |
| <kbd>i</kbd> | Index settings |
| <kbd>⌘</kbd><kbd>,</kbd> | Settings |
| <kbd>c</kbd> | Agent control |
| <kbd>h</kbd> | History: what happened, across every agent and repo |
| <kbd>b</kbd> | Browser |
| <kbd>p</kbd> | Toggle node previews |

## Map

| Keys | Action |
|---|---|
| Drag | Pan |
| <kbd>⌥</kbd> drag, or right/middle button | Orbit |
| Scroll | Zoom to the pointer |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Fly (hold <kbd>⇧</kbd> for speed) |
| <kbd>Q</kbd> <kbd>E</kbd> · <kbd>↑</kbd> <kbd>↓</kbd> | Orbit · tilt |
| <kbd>+</kbd> <kbd>-</kbd> | Zoom |
| <kbd>0</kbd> | Reset the view |
| <kbd>f</kbd> | Frame the selected node |

## Claude panel

| Keys | Action |
|---|---|
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>←</kbd> / <kbd>→</kbd> | Previous / next chat in the group |
| <kbd>⌃</kbd><kbd>⌘</kbd><kbd>←</kbd> / <kbd>→</kbd> | Move the chat to the group beside |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>\\</kbd> | Split right |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Toggle the 2×2 grid |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>F</kbd> | Full-window Claude |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>S</kbd> | Spread the tabs across the screen |
