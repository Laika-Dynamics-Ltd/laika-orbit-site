# laikaorbit.com

The website and docs for [Laika Orbit](https://github.com/Laika-Dynamics-Ltd/laika-orbit) and its
retrieval engine, Laika Orbit recall. Built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build).

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # static site in dist/
```

Docs pages are Markdown in `src/content/docs/docs/`; the sidebar is in `astro.config.mjs`.
Corrections are welcome: every page has an "Edit page" link.
